# Facial Emotion Recognition (EfficientNet-B0)

Project structure generated by `create_fer_project_structure.py`.

## Setup
```
pip install -r requirements.txt
```

## Workflow
1. Place FER2013 / CK+ / RAF-DB raw data in `dataset/raw/`
2. Run preprocessing to populate `dataset/processed/{train,validation,test}/<class>/`
3. `python train.py` to train
4. `python predict.py --image path/to/img.jpg` to test on a single image
5. `python app.py` to run webcam + backend pipeline

## Folder map
- `src/data` — Dataset, DataLoader, transforms
- `src/model` — EfficientNet-B0 definition
- `src/training` — train/evaluate loops
- `src/inference` — image/webcam inference, face detection, temporal smoothing
- `src/backend` — API client, session store, decision engine
- `configs/config.yaml` — all paths & hyperparameters
- `saved_models/` — checkpoints
